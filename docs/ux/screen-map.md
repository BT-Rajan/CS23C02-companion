# Screen map (proposed)
No bottom tab bar. Shallow stack: Home → Unit → Topic → Activity. Profile via one icon.

| # | Screen | Purpose | Primary action |
|---|---|---|---|
| 1 | Welcome | Create account / Sign in | Create account |
| 2 | Create account | Email + password | Continue |
| 3 | Verify email | 6-digit code | Verify |
| 4 | Sign in / Forgot / Reset | Recovery by emailed code | Sign in |
| 5 | Activate book | Enter / scan code | Activate |
| 6 | Home | **Continue** card + units list with completion marks | Continue |
| 7 | Unit | Topics with state; unit assessment entry at the end | Next topic |
| 8 | Topic (lesson) | Reader: explanation, examples, keywords, syntax box | Practise |
| 9 | MCQ practice | One question at a time | Check / Next |
| 10 | Code tracing | Predict output / step through | Check / Next |
| 11 | Exercise | Problem, editor, output pane, tests | Run / Check |
| 12 | Unit assessment | Questions, submit, result, review | Submit |
| 13 | Me | Progress by unit, assessment history, sign out, help | – |

Deferred and explicitly absent in release 1: search, bookmarks screen, notifications, leaderboards, streaks, settings sprawl. Bookmarking is replaced by Continue. A search can come later if usability tests show students can't find topics; the book's index is the first line of support.
